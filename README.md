# IranArchive

IranArchive now serves a small static dedication page.

The page is dedicated to the fallen heroes of the fight against the Islamic Republic, their families, and the Iranian people. It directs visitors to [IranTrial](https://irantrial.org/en) so documents and records can remain concentrated in one place.

IranArchive is not affiliated with IranTrial and does not work with IranTrial.
